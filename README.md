# SUSTech TIS 选课助手

这是一个只在你的电脑上运行的南方科技大学 TIS 选课辅助工具。它提供中文网页界面，让你可以登录 CAS、读取当学期可选课程、搜索课程、建立待选队列，并在**只读预演**或经明确确认后的真实提交模式下运行选课任务。

本项目不提供绕过限流、伪造流量、绕过验证码或多线程高频请求功能。所有选课请求经统一限流器处理；默认最小间隔为 1.2 秒。请遵守学校的相关规定，并仅使用自己的账户。

> **重要提示：TIS 的接口和选课规则可能随时变化。** 实际选课前，请先使用“只读预演”完成登录、学期读取、课程加载和队列检查。只读预演绝不会发送真正的选课提交请求。

## 目前可以做什么

- CAS 登录，使用同一个 `requests.Session` 维持登录周期；
- 获取当前学期和可选择的课程任务；
- 按课程名称或课程类别搜索，并将课程加入待选队列；
- 上移、下移或移除待选课程；
- 选择“优先级模式”或“循环模式”；
- 使用只读预演检查流程，或输入 `RUN` 后确认真实提交；
- 可选地将密码保存到 **macOS Keychain（钥匙串）**，而不是文本文件；
- 使用 `class.txt` 和命令行入口作为旧版兼容方式。

尚未实现的项目会在界面和代码中明确保留为后续工作；当前版本**没有**候补抢课上传、18:30 定时启动、通知、历史记录、系统诊断或实时日志面板。不要把它们当作可用功能。

## 第一次使用：最短步骤

### 1. 下载项目

在 GitHub 页面点击绿色的 **Code** 按钮，再点击 **Download ZIP**。解压到一个你找得到的位置，例如“下载”文件夹。你也可以使用 Git：

```bash
git clone https://github.com/ShiWei-000432/SUSTech_Tools.git
cd SUSTech_Tools
```

### 2. 确认安装了 Python 3

打开 macOS 的“终端”，输入：

```bash
python3 --version
```

看到 `Python 3.x` 即可。若提示找不到命令，请先从 [Python 官网](https://www.python.org/downloads/macos/) 安装 Python 3，再重新打开终端。

### 3. 启动网页界面

有两种等价方式，任选一种。

**更适合新手：** 在 Finder 中双击项目根目录的 `启动 TIS 选课助手.command`。macOS 会打开终端窗口，并在服务准备好后自动打开浏览器。

**使用终端：** 进入项目目录后运行：

```bash
./start.sh
```

第一次运行会自动安装所需 Python 依赖，可能需要等待一两分钟。服务正常运行后，浏览器会打开：

```text
http://127.0.0.1:8000
```

请让启动窗口保持打开。关闭该窗口会停止本地服务，浏览器会显示“连接被拒绝”。地址 `127.0.0.1` 只代表你的这台电脑，不会将服务公开到校园网或互联网。

> 不要双击 `web/templates/index.html`，也不要把它拖到浏览器中打开。那只是网页模板，不是可运行的网站，因此登录一定会失败。

## 网页操作说明

### 登录 CAS

打开页面后，输入学号和 CAS 密码，点击“登录”。密码默认只在本次运行的内存中用于登录，不会写入 `txt`、`json` 或日志文件。

如果希望下次少输入一次密码，可以勾选“记住密码到 macOS Keychain”。密码会由 macOS 钥匙串保存，而不是由本项目保存到磁盘。下次输入学号后点击“使用钥匙串密码登录”即可。请只在你本人使用的 macOS 账户中启用此选项。

登录成功后，页面顶部的 CAS 状态会变为“已登录”。若显示 `NETWORK_TIMEOUT`、`TLS_ERROR` 或 `TIS_SERVER_ERROR`，请先检查校园网、代理和 TIS 网站是否可访问；不要连续反复点击登录。

### 加载和搜索课程

登录后点击“刷新课程数据”。程序会先读取当前学期，再请求 TIS 返回的课程任务。成功后顶部会显示课程数量和学期。

在“课程搜索”区域输入课程名称、关键词或类别代码后点击“搜索”。课程类别来自 TIS，例如：

| 类别代码 | 一般含义 |
| --- | --- |
| `bxxk` | 通识必修选课 |
| `xxxk` | 通识选修选课 |
| `kzyxk` | 培养方案内课程 |
| `zynknjxk` | 非培养方案内课程 |
| `cxxk` | 重修选课 |
| `jhnxk` | 计划内选课新生 |

同一门课可能在不同类别下出现。请以 TIS 页面为准，选择自己实际有资格选择的那一项。

点击课程旁的“加入待选”，它会出现在“待选队列”。使用“上移”“下移”调整顺序，或“移除”删除不需要的课程。

### 先运行只读预演

页面第一次登录后的默认状态是“只读预演 ON”。保持它开启，设置队列后，在“运行任务”中选择模式并点击“开始”。程序会验证任务、课程和 Session，但每门课程都会标记为“只读预演：未发送选课提交请求”。

这一步适合在选课开始前确认 TIS 接口仍可用，也适合确认你没有选错课程。它不可能完成真正的选课。

### 两种任务模式

| 模式 | 行为 |
| --- | --- |
| 优先级模式 | 每轮只尝试队列中排在最前、仍在等待的课程。适合“先抢最重要的一门”。 |
| 循环模式 | 每轮按队列顺序尝试所有仍在等待的课程。适合多个课程同等重要。 |

任务使用单一工作线程，队列读写受锁保护，不会通过多个并发线程同时提交请求。任务可以在页面中暂停、继续或停止；停止时会请求工作线程安全退出。

### 真实提交前的确认

只有你主动点击“关闭只读预演”后，页面才会进入“真实提交 ON”。此时点击开始前，还必须在输入框中准确填写：

```text
RUN
```

这是防止误操作的第二道确认。真实提交会调用当前保留的 TIS 选课请求参数；成功、已满、冲突、已选等服务器结果会显示在任务条目中。网络故障、会话失效或接口响应异常会停止当前流程或报告错误，不能保证选课成功。

## 命令行兼容方式

如果你已使用旧版 `class.txt` 工作流，可以继续运行：

```bash
python3 cli.py
```

`class.txt` 一行一个课程名称，程序会以 UTF-8 with BOM 兼容方式读取它。命令行会先登录、加载课程并让你选择模式和是否只读预演。新用户优先使用网页，因为网页不要求手工编辑 `class.txt`。

原始的 `main.py` 没有被删除，用于保留旧项目的兼容基线；它属于旧实现，不建议新用户直接运行。新 Web 入口是 `app.py`，新 CLI 入口是 `cli.py`。

## 常见问题

### 浏览器显示“127.0.0.1 拒绝连接”

本地服务没有运行，或启动它的终端窗口已经关闭。重新双击 `启动 TIS 选课助手.command`，或者在项目目录运行 `./start.sh`，并保持该窗口开启。

### 显示“无法访问您的文件”或 `ERR_FILE_NOT_FOUND`

你打开了本地 HTML 文件而不是 Web 服务页面。关闭该标签页，重新通过启动脚本打开 `http://127.0.0.1:8000`。

### 学号和密码正确，但登录失败

CAS、TIS、校园网络或代理都可能暂时异常。等待一段时间后再试，并在浏览器中手动确认学校 CAS 页面是否可打开。请勿将密码、Cookie、Session Token 或浏览器网络请求中的认证信息发给他人。

### 我勾选了记住密码，密码保存在哪里？如何删除？

它保存在 macOS 的“钥匙串访问”中，服务名称为 `SUSTech TIS 选课助手`，账号为你的学号。你可以在“钥匙串访问”搜索该名称并删除对应条目。本项目不会把密码写入 `user.txt`、`config.json`、课程缓存或日志。

### 为什么课程加载失败或搜索不到课程？

可能是当前不在选课开放期、账号没有相应选课资格、TIS 返回内容变化，或网络请求失败。先重新刷新课程数据；若仍失败，保留错误代码和不含隐私的日志信息后再反馈问题。不要猜测或改动 TIS 参数。

## 项目文件说明

```text
SUSTech_Tools/
├── app.py                         # 本地 Web 服务启动入口
├── cli.py                         # 新的命令行兼容入口
├── main.py                        # 原项目旧版入口，保留兼容基线
├── start.sh                       # 安装依赖并启动 Web 服务
├── 启动 TIS 选课助手.command       # Finder 双击启动器
├── requirements.txt               # Python 依赖
├── sustech_tools/                 # 与界面解耦的登录、课程、任务核心服务
├── web/                           # 网页模板与样式
├── tests/                         # 完全 mock 的回归测试
├── docs/CODE_AUDIT.md             # 旧版代码审计和改造依据
├── class.txt                      # 旧版待选课程名单（兼容）
├── course.txt                     # 旧版课程缓存（兼容）
├── data/                          # 本机生成的新课程缓存，不上传 Git
└── logs/                          # 本机运行日志，不上传 Git
```

## 安全与隐私

- TLS 证书验证默认开启；不通过 `verify=False` 绕过证书问题。
- 统一网络客户端设置超时，并区分网络、TLS、HTTP、JSON、限流和登录异常。
- 日志过滤密码、Cookie、Authorization 和 token 等认证信息。
- 课程缓存和日志仅保存在本机，并已排除在 Git 之外。
- 如果你曾在聊天、截图或公开位置发送过 CAS 密码，请立即到 CAS 修改密码。
